My portfolio is built with **Next.js and React**, two modern technologies used to create fast and responsive web applications.  
%
The application uses **TypeScript** for code robustness, **Tailwind CSS** for responsive design, and **Zustand** to manage global state (conversations, user settings, language).  
%
From an algorithmic perspective, I implemented an **intelligent matching system** that analyzes your question by normalizing it, breaking it down into keywords, and then calculating a relevance score for each predefined question. The algorithm notably uses **Levenshtein distance** to tolerate typos.  
%
The application is fully **bilingual** (French/English) with separate content files for each language, and conversations are **saved locally** in your browser.
