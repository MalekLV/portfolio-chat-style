I completed this project during my third year at the IUT of Computer Science in Toulouse. The project consisted of creating a **recommendation AI** using the textual subtitles of TV series, working in a team of 2 people.  
%
Here is the project workflow:  
- Data cleaning and preparation  
- Programming the **search algorithm** with a **full-text search index** based on **SQLite FTS5**  
- Creating a user rating system  
- Programming the **recommendation algorithm**, analyzing user ratings and suggesting similar TV series  
%
All programming was done using **Python** with **VSCode**.
